# Snug Puzzle Studio website

Static site for the studio, the **Nap Spots privacy policy** and the AdMob **app-ads.txt** file.

| File | Purpose |
|---|---|
| `index.html` | Studio home page (use this URL as the "Website" in Play Console) |
| `privacy.html` | Privacy policy for Nap Spots (paste this URL into Play Console → App content → Privacy policy) |
| `app-ads.txt` | Authorises AdMob to sell ads in our apps. It must sit at the **root** of the website listed in Play Console |

Hosted free with GitHub Pages. This repository must be **public**, named `RaviSanchala01.github.io`, so the files appear at:
- https://ravisanchala01.github.io/
- https://ravisanchala01.github.io/privacy.html
- https://ravisanchala01.github.io/app-ads.txt
